# Issue tracker: GitHub

Track work in SimonGelbart/book-manager using the connected GitHub
integration, or gh when available.

Repository documents are the source of truth for requirements and design.
Issues contain task-specific acceptance criteria and progress, and link
to the relevant documents.

When publishing a specification, commit the document and create or update
a tracking issue linking to it.

Before changing an issue, read its description, comments, and labels.

PRs as a request surface: no.
