## Agent skills

### Branches and commits
Before starting a branch or preparing a pull request, read
docs/planning/working-agreement.md for the agreed branch and commit workflow.

### Requirements interview
During grilling, ask exactly one question per message and wait for the
answer before asking the next. Apply this project preference when a
skill's default workflow groups multiple questions into a round.

### Issue tracker
Before managing specifications or tasks, read docs/agents/issue-tracker.md.

### Triage labels
Before classifying issues, read docs/agents/triage-labels.md.

### Domain docs
Before exploring or changing the domain, read docs/agents/domain.md.
