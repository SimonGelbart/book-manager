# Personal EPUB collection

The user's downloaded EPUB reading collection, its organization, and their own reading history and notes, with richer metadata for AO3 works.

## Language

**Collection**:
The user's personal set of works and downloaded EPUB copies, together with their reading history and notes.

**Work**:
A piece of writing catalogued independently of its EPUB copies and downloaded versions. It can come from AO3 or another source.

**AO3 work**:
A work published as one work on Archive of Our Own, distinct from any downloaded EPUB copy.
_Avoid_: Book, story in project documentation when this specific concept is intended.

**EPUB copy**:
One downloaded EPUB file containing a work. Several EPUB copies can represent the same or different downloaded versions of that work.

**Downloaded version**:
A snapshot of a work's content, potentially represented by several EPUB copies. A download with ten chapters and a later download with twelve chapters are different downloaded versions. A revision to existing chapter text also creates a different downloaded version, even when the chapter count stays the same.

**Word count**:
The length of a work in words as reported by a particular downloaded version.

**AO3 completion status**:
Whether an AO3 work is complete or unfinished according to the metadata in a downloaded version. It describes the work's publication state, independently of the user's reading status.

**Identical duplicate**:
An additional EPUB copy containing the same downloaded version without changes to its chapter text. Copies of the same work can be identical duplicates despite differences in covers, fonts, or layout.

**Duplicate indicator**:
A visible indication that identical duplicate EPUB copies exist for a work.

**Reading status**:
The user's declared progress state for a work: Unknown, Unread, Reading, Read, or Dropped. It is shared across that work's EPUB copies.

**Read version**:
A downloaded version that the user has explicitly marked as read for a work. It identifies the snapshot read, independently of other downloaded versions in the collection.

**Needs review**:
An import-review condition indicating ambiguous identification or work association. It is separate from the user's personal reading status.

**New chapters indicator**:
A signal that an imported downloaded version contains additional chapters beyond the version previously marked Read. It accompanies the Read status while preserving the earlier reading record.

**Text revised indicator**:
A signal that a newer imported downloaded version revises existing chapter text relative to a read version, including revisions that leave the chapter count unchanged. It is distinct from the new chapters indicator.

**Personal rating**:
The user's own optional assessment of a work on a 1–5-star scale in half-star steps, distinct from source-provided content classifications such as an AO3 content rating.
_Avoid_: Grade or rating alone when it could be confused with AO3 content rating.

**Like**:
The user's optional indication that they like a work, available independently of reading status and personal rating. A work can be liked even when it is unread or unrated.

**AO3 content rating**:
AO3's classification of a work's content, separate from the user's personal rating.

**Personal note**:
An editable text record of the user's own thoughts about a work, shared across its EPUB copies.
