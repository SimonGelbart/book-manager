# Personal EPUB collection

The user's downloaded AO3 reading collection, its organization, and their own reading history and notes.

## Language

**Collection**:
The user's personal set of AO3 works and downloaded EPUB copies, together with their reading history and notes.

**AO3 work**:
A piece of writing published as one work on Archive of Our Own, distinct from any downloaded EPUB copy.
_Avoid_: Book, story in project documentation when this specific concept is intended.

**EPUB copy**:
One downloaded EPUB file containing an AO3 work. Several EPUB copies can represent the same or different downloaded versions of that work.

**Downloaded version**:
A snapshot of an AO3 work's content, potentially represented by several EPUB copies. For example, a download with ten chapters and a later download with twelve chapters are different downloaded versions.

**Identical duplicate**:
An additional EPUB copy containing the same downloaded version without changes to the work's content.

**Duplicate indicator**:
A visible indication that identical duplicate EPUB copies exist for an AO3 work.

**Reading status**:
The user's declared progress state for an AO3 work: Unknown, Unread, Reading, Read, or Dropped. It is shared across that work's EPUB copies.

**New chapters indicator**:
A signal that an imported downloaded version contains additional chapters beyond the version previously marked Read. It accompanies the Read status while preserving the earlier reading record.

**Personal rating**:
The user's own optional assessment of an AO3 work on a 1–5-star scale in half-star steps, distinct from its AO3 content rating.
_Avoid_: Grade or rating alone when it could be confused with AO3 content rating.

**Like**:
The user's optional indication that they like an AO3 work, available independently of reading status and personal rating. A work can be liked even when it is unread or unrated.

**AO3 content rating**:
AO3's classification of a work's content, separate from the user's personal rating.

**Personal note**:
Text the user writes to record their own thoughts about an AO3 work, shared across its EPUB copies.
